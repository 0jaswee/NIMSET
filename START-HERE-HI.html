NIMCET + JILCCE Tracker — r7

अब पहले Google login, फिर दो syllabus के विकल्प मिलेंगे। पुराने NIMCET topics, notes, planner और progress के लिए वही storage keys और Firebase document main रखा गया है। JILCCE का document jilcce अलग है।

Update के आसान steps

  1. पुरानी वेबसाइट पर Account → Export JSON से अपना NIMCET backup डाउनलोड कर लें। Personal backup को GitHub में upload न करें।
  2. इस ZIP को extract करें। इसके अंदर की सभी files और tests folder को उसी GitHub repository के root में upload करके existing files replace करें। ZIP या उसके बाहर वाला folder upload न करें। Repository और Pages address वही रखें।
  3. इस package में आपके मौजूदा nimcet-study-tracker project का public Firebase web config पहले से भरा है। कोई password/service-account secret शामिल नहीं है। अगर आप अलग Firebase project इस्तेमाल करते हैं, तो अपना सही config रखें।
  4. ज़रूरी — Firebase Console → nimcet-study-tracker → Firestore Database → Rules. ZIP की firestore.rules को text editor में खोलें, पूरा text copy करके Rules editor में replace करें, फिर Publish दबाएँ। इससे केवल signed-in user अपने ही main और jilcce documents पढ़/लिख पाएगा। Database या project delete न करें। पुराने main rules में JILCCE की अनुमति नहीं है; update किए बिना उसका sync नहीं चलेगा।
  5. GitHub Pages deployment पूरा होने के बाद वेबसाइट refresh करें। ज़रूरत पर Ctrl+Shift+R करें। वही Google account चुनें जिससे पहले sync करते थे। फिर NIMCET या JILCCE खोलें और ऊपर status देखें। केवल Synced दिखने पर cloud save मानें।

Notes: colour और PDF

किसी topic के More → Notes & Links में लिखें। जिस text का colour बदलना है उसे select करके colour, Bold, Italic या Underline दबाएँ। फिर Save notes करें। पुराने plain notes भी बने रहेंगे। Clear style चुने हुए text की formatting हटाता है।

Export PDF से browser का Print dialog खुलेगा। Destination में Save as PDF चुनें और Save करें। यह direct PDF download नहीं है। Hindi fonts browser/device से आते हैं। Mobile में Print / Save to PDF का नाम अलग हो सकता है। इस button से उसी topic के notes export होते हैं। पूरा backup Account → Export JSON से लें।

दो अलग study spaces

ऊपर Switch syllabus से बदलें। हर syllabus के अपने notes, plans, tests, goals और completion हैं। Backup export/import भी चुने हुए syllabus के लिए है। पुराने NIMCET JSON को NIMCET में ही import करें। दूसरे syllabus का backup गलत जगह import होने से रोक दिया गया है।

Login private sync के लिए आवश्यक है। Firebase config missing होने पर setup guidance दिखेगी; login bypass या fake synced status नहीं है। पहली sign-in के लिए internet चाहिए।

JILCCE content के बारे में

आपकी 14-page PDF से 230 subjects/topics/subtopics/study-guidance nodes बने हैं। Hindi-English headings readable रूप में रखे हैं; PDF के पुराने font की extraction errors normalize की गई हैं। More → Provided PDF reference में page और original extracted text मिलता है। PDF एक supplied study guide है; उसके marks/question-count/importance claims को official verified notification नहीं माना गया है। जो अतिरिक्त अभ्यास सुझाव हैं उन्हें अलग label किया गया है। मूल PDF इस ZIP में शामिल नहीं है।
