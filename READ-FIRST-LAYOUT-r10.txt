यह छोटी PATCH ZIP है; पहले भेजी गई NIMSET r9 वाली पूरी ZIP के ऊपर लगाएँ। यह standalone पूरा app नहीं है।

अपलोड:
1. मौजूदा app से NIMCET और JILCCE का अलग-अलग निजी JSON backup सुरक्षित कर लें।
2. ZIP Extract All करें। इसके अंदर app.js आदि सीधे root में हैं।
3. GitHub में वही branch/folder खोलें जहाँ existing index.html है। Add file > Upload files में ZIP के अंदर की 5 app files और tests folder upload करके same-name files replace करें। ZIP या enclosing folder upload न करें। बाकी existing files delete न करें।
4. Commit करें, Pages deployment होने दें, फिर site refresh करें। Account में Version r10 दिखेगा। जरूरत हो तो app tabs बंद करके दोबारा खोलें; browser storage clear न करें।
5. Firebase में कोई नया बदलाव नहीं चाहिए।

बदला क्या है:
• Home और topic rows में छोटा Video icon और More icon। Row का Practice हटाया; Practice Quiz tab में मौजूद है।
• More में Description / Notes & Links / Quiz पहले जैसे। Notes & Links के अंदर Study video button हटाया है।
• Video icon से अलग पूरा video + notes screen: सबसे ऊपर video; नीचे एक horizontal bar जिसमें Back, −30 sec, Play/Pause, +30 sec, speed, video chooser और PDF हैं; उसके नीचे Notes/Save/Cancel और collapsible formatting। Close/× button नहीं है।
• YouTube native controls=0, custom controls नीचे। YouTube branding, ads, loading/error overlays YouTube के नियंत्रण में हैं; इनके पूरी तरह छिपने का दावा नहीं है। Autoplay browser पर निर्भर है; जरूरत पर Play दबाएँ।
• Keyboard पर available visual viewport में video ऊपर बना रहता है और notes का बाकी हिस्सा scroll होता है। पुराने scrolling layout की तरह keyboard पर video हटता नहीं है। बहुत कम landscape height में keyboard बंद करके पढ़ना अधिक उपयोगी हो सकता है।
• Save/Cancel से video restart नहीं होता। Unsaved notes पर Back रोककर Save/Cancel करने को कहता है। Original playback minutes, quizzes, progress, marks, source curriculum और cloud/storage paths बदले नहीं हैं।
